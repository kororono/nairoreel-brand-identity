## Typefaces

### Playfair Display — Display / Editorial
- Source: Google Fonts
- Weights used: 400 (regular), 400 italic, 700 italic, 900
- Role: headlines, post titles, display type on thumbnails
- Character: editorial, cinematic, high-end press

### Montserrat — UI / Body / Labels
- Source: Google Fonts
- Weights used: 300, 400, 500, 600, 700, 800
- Role: captions, metadata, labels, body copy, all-caps callouts
- Character: clean, geometric, modern

## Casing Rules

| Context           | Rule                                                        |
|-------------------|-------------------------------------------------------------|
| Post headline     | Title Case (Playfair Display, weight 700–900)               |
| Eyebrow / label   | ALL CAPS, wide tracking (Montserrat 600–700, 0.4em)         |
| Body copy         | Sentence case                                               |
| Metadata / dates  | ALL CAPS, tight (Montserrat 500, 0.2em)                     |

---

## On-Post Typography Rules (IG Thumbnails)

- Every post has at least one text element — no raw image exports
- Headline sits on a readable dark surface or with enough contrast treatment
- Eyebrow label above headline when hierarchy needs two levels
- Max 2 typefaces per post (Playfair + Montserrat only)
- Italic Playfair = editorial mood / cinematic
- Bold Montserrat caps = technical / data / energy
