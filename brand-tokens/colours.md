## Primary Palette

| Token        | Name      | Hex       | Usage                                      |
|--------------|-----------|-----------|--------------------------------------------|
| `--black`    | Black     | `#000000` | Backgrounds, dominant surface              |
| `--red`      | Red       | `#EA1821` | Primary accent, CTAs, section markers      |
| `--white`    | White     | `#FFFFFF` | Type on dark, light-mode base              |
| `--off-white`| Off-White | `#F2F0ED` | Warm light alternative, paper feel         |

## Extended Palette

## Surface Tokens

| Token           | Hex       | Usage                          |
|-----------------|-----------|--------------------------------|
| `--dark-surface`| `#0A0A0A` | Page/canvas background         |
| `--dark-card`   | `#111111` | Card / panel backgrounds       |
| `--dark-border` | `#1E1E1E` | Dividers, grid gaps            |
| `--muted`       | `#555555` | Secondary text, metadata       |

## Grain / Texture

- Grain overlay opacity: `0.04` (very subtle — just enough to add depth)
- Apply as fixed pseudo-element above content, `pointer-events: none`
