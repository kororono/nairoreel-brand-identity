## Export Config

| Output Type    | Dimensions    | Format | Destination          |
|----------------|---------------|--------|----------------------|
| Square post    | 1080×1080     | JPG    | outputs/posts/       |
| Reels cover    | 1080×1920     | JPG    | outputs/reels-covers/|
| YT thumbnail   | 1280×720      | JPG    | outputs/thumbnails/  |

## File Naming Convention

`YYYY-MM-DD_[campaign]_[content-type]_v[n].jpg`

Examples:
- `2026-04-10_dark-red_render-showcase_v1.jpg`
- `2026-04-12_midnight_bts-process_v2.jpg`
