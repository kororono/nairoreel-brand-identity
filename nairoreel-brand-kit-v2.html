01
Brand Philosophy
Young creative studio — confident, professional, with a hint of fun. Not corporate. The grid should look like a bunch of talented young people running a serious studio.

Every post passes through the same machine.

The source material will always vary — different clients, colours, scenes. What cannot vary is the treatment. Every post gets the border. Every post gets the grain. No exceptions.

The grid is a curation decision, not a documentation habit.

What goes on the main grid is a deliberate design call. Not everything gets posted. Not every scene from a project is the right thumbnail. Choose intentionally.

If one post can't fit, split into three.

A project that fights the visual identity on a single post becomes a full row of three. Row-level identity — paired with border and grain — can carry anything.

Openbook Studio is the benchmark.

Different content every post, one unmistakable filter. That level of cohesion is the target. The system is what makes it replicable without us in the room.

04
Treatment System
The system that makes every post look like it came from the same studio. A universal base applied to everything, with named treatments for specific content types.
Universal Base — Every Post, No Exceptions

Border + Grain. Always.

Before any other treatment is applied, every single post on the grid gets these two layers. No post skips them.

Layer 1

Black Border Frame

6px solid #000000, inset on all four edges. Contains off-brand colours. Signals that this image passed through Nairoreel's hands.

Layer 2

Film Grain Overlay

Monochromatic noise texture at 15% opacity. Unifies the tactile feel across all posts regardless of source colour temperature.

Layer 3

Colour Grade

Deepen blacks. Cool temperature shift. Reduce saturation. Strength varies by post — Low, Medium, or High. See Filter Spec.

Named Treatments
Treatment A

Dark Frame + Label

For colourful client work that can't be changed
  • Universal base (border + grain + Filter Medium)
  • Eyebrow label — Montserrat 700, ALL CAPS, white, tracked — bottom-left
  • 2px #EA1821 accent line directly above the label
  • Let the image breathe — no headline, no overlay, no logo
Treatment B

Dark Overlay + Typography Hero

For strong visuals needing editorial framing
  • Universal base + Filter Low
  • 50% opacity #000000 overlay across the image
  • Playfair Display headline — 900 weight, white, 2–4 words, large scale
  • Optional: Montserrat ALL CAPS label in #EA1821 above headline
Treatment C

Studio Card Split

For hero shots that need context
  • Universal base on the image portion
  • Image: 60% of canvas (top or left)
  • #111111 panel: remaining 40%
  • In panel: eyebrow + 2px red line + Playfair headline + optional descriptor
Treatment D

Full Dark Composition

For new planned row campaigns
  • Full brand palette background — not the source image
  • Source image composited in as a design element
  • Universal base grain across the whole composition
  • Typography as part of the composition, not an overlay

Grid & Row System
The grid reads in rows of 3. Each row is a visual campaign — shared colour, mood, and content type. This is the primary tool for creating cohesion when individual posts vary.
Campaign Row 01

Dark Red

Cinematic, dramatic, high-energy. Studio at its most confident. Shadow tone has a faint red undertone.

Campaign Row 02

Midnight

Deep, cinematic, technical. VFX, 3D, and motion work. Shadow tone has a faint #180161 midnight undertone.

Campaign Row 03

Neutral Dark

Human, documentary, warm but controlled. The studio behind the studio. Strictly neutral grade — no colour cast.

Campaign Row 04

Orange Burst

Warm, energetic, personality-forward. Allow warm amber-orange in highlights. Shadows stay dark and neutral.

Grid Rules
01

The grid reads in rows, not posts.

Design each row as a campaign. Three posts, one shared mood. The viewer's eye scans left to right — make that scan feel intentional.

02

If one post can't fit — split it into three.

A project that fights the grid as a single post becomes a full row of three. Row-level identity, border, and grain can carry any source material.

03

Pick the right scene, not the most complete one.

For projects with multiple scenes, pick the thumbnail that needs the least treatment to belong. If a scene benefits from simple graphic design on the thumbnail, do that instead.

04

Not everything goes on the main grid.

Event flyers, client deliverables, raw exports — these go to Reels or stories where appropriate, unless framed with Treatment A. The main grid is curated, not documented.

05

Reels and Carousels follow the same rules.

Reels thumbnail must be intentionally designed — not the auto-generated frame. Carousel first image must align with grid-level visual identity.

06

The thumbnail is a design decision.

The cover image for any piece of content is chosen and designed — it is not a default export. Treat it as a post in its own right.

08
Logo Use
Minimal. The grid is already ours — we don't need to stamp every post. Use the logomark only when it genuinely enhances the design, or when it functions as a graphic element rather than a signature.

When to Use

Only when the logo actively improves the composition — as a design element that earns its place. Not as a default watermark. Not out of habit. If removing it makes the post look cleaner, remove it.

6px black border
NRR

If Used — Placement & Version

Bottom-right corner only. White version only. 8% of canvas width. No other position, no other colour, no outline, no shadow. Do not scale above 10% of canvas width.


Default Assumption

For most posts: no logo. The border, grain, and treatment do the branding. The grid as a whole signals the studio — individual posts do not need to repeat that message on every frame.

Decision Tree
Use this when you have a post or thumbnail to design and aren't sure which treatment to apply.

What treatment does this post need?

1
Is the source image dark, cinematic, or near-monochrome?
Yes → Apply universal base + Filter Low. Done. No further treatment needed.
2
Is the image warm-toned or moderately colourful?
Yes → Apply universal base + Filter Medium. Check if it sits in the grid. If yes, done. If still too warm, continue.
3
Can row-level identity carry it? (Place in a matching campaign row)
Yes → Assign to appropriate campaign row + Filter Medium. The row does the cohesion work. Done.
No → Continue.
4
Is this a client deliverable or event flyer?
Yes → Apply Treatment A (Dark Frame + Label) to frame it as studio output. Or move to Reels / stories if the graphic style is incompatible.
No → Continue.
5
Is there a better scene or thumbnail from the same project?
Yes → Use that instead. Start over from step 1.
No → Continue.
6
Can this project be split into 3 posts for a full row?
Yes → Split it. Plan the row with a campaign colour. Row identity + border + grain handles the rest.
No → Continue.
7
Apply Level 3 — Monochrome + Accent Typography
Desaturate fully. Add minimal #EA1821 label bottom-left with 2px accent line. Apply Filter High. If it still doesn't work — move it to Reels or stories where appropriate. Not everything belongs on the main grid.
10
Workflow
How a post goes from source material to grid. This process applies to new content and to retrofitting existing posts.
1

Curate — decide what goes on the grid

Is this the right scene? Is there a better thumbnail? Should this be a single post or a 3-post row? Stories or main grid? Make these decisions before opening Canva.

2

Plan the row

Which campaign row does this post belong to? What are the other two posts in that row? Plan all three before designing any of them so the row reads as intentional.

3

Apply the treatment in Canva

Use the decision tree to pick the treatment. Apply universal base first (border + grain). Then the Nairoreel Filter at the appropriate strength. Then any named treatment on top.

4

Check against the row and the grid

Export and place it in context. Does it look like it belongs in the row? Does the row look like it belongs on the grid? If not, adjust the grade strength before posting.

5

Export and name the file

Export at 1:1 (posts) or 9:16 (Reels cover). Name using the convention below.

File Naming Convention

YYYY-MM-DD_[campaign]_[content-type]_v[n].jpg

11
Never Do
Six rules. If you're about to break one of these, stop and go back to the decision tree.
1
Post a raw export to the main grid without border and grain applied.
2
Use any font other than Playfair Display or Montserrat in any design element.
3
Add text to a post where the treated image can stand alone — avoid text if you can.
4
If using the logo: place it anywhere other than bottom-right, or use any version other than white.
5
Use a colour not in the brand palette for any design element, border, or type.
6
Post an event flyer or client deliverable directly — frame it with Treatment A or move it to Reels / stories where appropriate.

Treatment Blocks — Swap per post
Pick one. Add it below the Constant Block. Then add a Campaign Block if the post belongs to a row.
Filter Low
Dark / Cinematic posts — already close to brand
Apply the universal base. Then apply a light cinematic colour grade: deepen blacks slightly, reduce global saturation by 10%, apply a very subtle cool temperature shift. Keep it natural — the image should still feel like itself, just more cohesive.
Filter Medium
Warm-toned / moderately colourful posts
Apply the universal base. Then apply a moderate cinematic colour grade: deepen blacks, reduce global saturation by 20%, apply a cool temperature shift (push slightly toward blue-grey, not cyan). The image should feel like it passed through the same camera as the rest of the grid.
Filter High
Rescue mode — bright or saturated source images
Apply the universal base. Then apply a strong cinematic colour grade: crush the blacks, reduce global saturation by 40–50%, strong cool temperature shift. The image should move significantly toward neutral dark. Prioritise grid cohesion over preserving the original colour temperature.
Monochrome + Accent
Level 3 — last resort
Apply the universal base. Desaturate the image fully to monochrome (greyscale). Then add minimal typography: - Short ALL CAPS label in Montserrat 700, #EA1821 red, tight letter-spacing, bottom-left - 2px horizontal #EA1821 accent line above the label No other text. No logo. Do not add a headline unless the image genuinely cannot stand alone.
Treatment A — Dark Frame + Label
Client work / deliverables framed as studio output
Apply the universal base + Filter Medium colour grade. Then add: - Eyebrow label: Montserrat 700, ALL CAPS, white, 1.5px letter-spacing, 11px — infer a short label from the image content (e.g. "PRODUCTION" / "CLIENT WORK" / "BRAND FILM") - 2px solid #EA1821 horizontal accent line directly above the label - Both positioned bottom-left, 20px from the edge, consistent margin Do NOT add a headline. Do NOT add a logo. Let the image breathe inside the frame.
Treatment B — Dark Overlay + Typography Hero
Strong visuals needing editorial framing
Apply the universal base. Then: - Apply a 50% opacity #000000 overlay across the image - Add a bold Playfair Display headline, 900 weight, white, 2–4 words, editorial tone — infer from image content - Position: centre-left or bottom-left, large scale - Optional: small Montserrat ALL CAPS label in #EA1821, 10px, above the headline Apply Filter Low grade on top.
Treatment C — Studio Card Split
Hero shots needing context — 3D, architecture, technical work
Apply the universal base to the image portion. Then: - Image occupies 60% of the canvas (top or left portion) - Solid #111111 panel occupies the remaining 40% - In the panel: · Montserrat 700 ALL CAPS eyebrow label, white, tracked — infer from image (e.g. "3D VISUALISATION") · 2px #EA1821 accent line below the label · Playfair Display headline, 700 weight, white, 2–4 words · Optional: one-line descriptor in Montserrat 300, #888888 - Apply Filter Low grain to the panel as well
Treatment D — Full Dark Composition
New planned campaigns — maximum brand control
Do not use the source image as a background. Instead: - Create a full brand palette background using [SPECIFY: #000000 / #0A0A0A / #180161 / #4F1787] - Composite the source image into the composition as a design element — cropped, masked, or treated - Apply the universal base grain across the entire composition - Add typographic elements using Playfair Display and Montserrat as needed - The source image is a component, not the canvas
