# Nairoreel — 9-Post Grid Plan (First 3 Rows)

Each row is a visual campaign. Posts within a row share a campaign colour, mood, and consistent treatment.
Border + grain is universal. Campaign colour and content type define the row.

Grid reads left to right, top to bottom. Rows 1–3 are the first impression.

---

## Row 1 — Dark Red Campaign
*Mood: Cinematic. Dramatic. High-energy. Studio at its most confident.*
*Campaign colour: #EA1821 red used as accent, deep black as base.*

| Position | Content | Treatment | Notes |
|---|---|---|---|
| 1.1 | Post 8 (silhouette, red wash) | Base + filter Low | Already works. Anchors the row. |
| 1.2 | New: Cinematic close-up or dramatic BTS shot | Treatment B (dark overlay + Playfair headline) | Commission or pull from existing footage |
| 1.3 | Post 1 (dark moody portrait) | Base only | Strongest post on grid. Closes the row. |

**Row logic:** Opens with drama (red silhouette), deepens with an editorial treatment (1.2), closes with restraint (dark portrait). All three feel like the same machine made them.

---

## Row 2 — Midnight Campaign
*Mood: Deep, cinematic, technical. VFX / production work. Studio doing the serious stuff.*
*Campaign colour: #180161 Midnight / #4F1787 Violet as underlying grade, near-black.*

| Position | Content | Treatment | Notes |
|---|---|---|---|
| 2.1 | Post 5 (Reload can, stormy sky) | Base only | Moody product photography fits here |
| 2.2 | Post 4 (workspace/documentary) | Base + filter Medium + desaturate | Pulls warm tones into the dark campaign |
| 2.3 | New: VFX / 3D / motion graphics frame | Treatment D (full dark composition) OR Treatment C (studio card split for the 3D work) | Use 3D house render with Treatment C, or commission a new dark 3D frame |

**Row logic:** Product photography → behind the scenes → studio technical work. Shows range within a consistent dark production mood. The Midnight colour grade ties all three.

---

## Row 3 — Neutral Dark Campaign
*Mood: Human, documentary, warm but controlled. The studio behind the studio.*
*Campaign colour: Neutral dark — #0A0A0A base, no strong accent. Let the images carry it.*

| Position | Content | Treatment | Notes |
|---|---|---|---|
| 3.1 | Post 10 (B&W portrait 1) | Base only | Already monochrome, already brand. |
| 3.2 | Post 3 (golden hour portrait) | Base + filter Medium + desaturate warm tones | Partially desaturated, the warmth becomes a controlled contrast within the neutral row |
| 3.3 | Post 11 (B&W portrait 2) | Base only | Closes the B&W bookend symmetry |

**Row logic:** Black and white bookends (3.1 and 3.3) with a warm-toned centre (3.2). The filter brings 3.2 toward neutral without destroying it. The row reads as "photography and people" — human work from the studio.
